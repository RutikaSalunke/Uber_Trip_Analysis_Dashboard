# Uber_Trip_Analysis_Dashboard
Interactive Power BI dashboard for Uber Trip Analysis using DAX, Power Query, Data Modeling, KPI Development, Drill-through Reports, and Business Intelligence Visualization.

## 📌 Project Overview

This Power BI project analyzes Uber trip data to uncover booking trends, vehicle performance, location insights, revenue patterns, and time-based demand. The dashboard provides interactive visualizations and business intelligence insights to support data-driven decision-making.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- CSV Dataset

## 📊 Dashboard Pages

### 1. Overview Analysis
- Total Bookings
- Total Booking Amount
- Average Trip Distance
- Vehicle Type Analysis
- Payment Type Analysis
- Pickup & Dropoff Analysis

### 2. Time Analysis
- Bookings by Hour
- Bookings by Day
- Hour-Day Heatmap
- Drill-through Analysis

### 3. Details Page
- Detailed Trip Records
- Interactive Filtering
- Complete Booking Information

## 📈 Key Insights

- UberX is the most preferred vehicle category.
- Day trips contribute more bookings than night trips.
- Peak booking activity occurs during daytime and evening hours.
- Certain pickup locations generate significantly higher demand.
